========================================================================
GUIDELINES FOR TESTING PHASE OF ATTACKS
========================================================================

--- PHASE 1: ENVIRONMENT RESET (GAWIN BAGO MAG-DEMO) ---
Bago mag-simula ang anumang attack simulation, siguraduhing malinis ang logs at directories.

1. I-clear ang Active Response logs para malinis ang monitor:
   sudo truncate -s 0 /var/ossec/logs/active-responses.log

2. I-clear ang FIM directory (para sa Ransomware test):
   sudo rm -rf /tmp/important_files/*
   mkdir -p /tmp/important_files

3. I-restart ang Wazuh Manager at Agent para ma-refresh ang sensors:
   sudo systemctl restart wazuh-manager
   sudo systemctl restart wazuh-agent


--- PHASE 2: ATTACK EXECUTION & MONITORING ---
Sundin ang sequence na ito para maipakita ang automated SOAR mitigation.

1. Buksan ang Log Monitor sa kanang terminal:
   sudo tail -f /var/ossec/logs/active-responses.log

2. Sa kaliwang terminal (remote_worker), patakbuhin ang napiling attack:
   - Rule 100001 (Ransomware):  ./ransomware_sim.sh
   - Rule 100002 (Port Sweep):  ./attack_scan.sh
   - Rule 5763 (SSH Brute):     ./ssh_bruteforce.sh
   - Or gamitin ang manual SSH brute force loop kung kailangan:
     for i in {1..8}; do ssh -o StrictHostKeyChecking=no wazuhadmin@172.16.16.100; done

3. Abangan ang "Successfully blocked IP" sa kanan.
4. Ipakita ang Sophos XG Web GUI para patunayan na na-add ang IP sa Wazuh_Blacklist_Group.


--- PHASE 3: MASTER CHEAT SHEET (IMPORTANT COMMANDS) ---

* WAZUH MANAGEMENT:
  - Restart Manager:    sudo systemctl restart wazuh-manager
  - View Live Logs:     sudo tail -f /var/ossec/logs/active-responses.log
  - Clear Logs:         sudo truncate -s 0 /var/ossec/logs/active-responses.log

* NETWORK CONFIGURATIONS (BATANGAS HUB PC):
  - I-edit ang Netplan: sudo nano /etc/netplan/00-installer-config.yaml
  - Apply Netplan:      sudo netplan apply
  (Note: Ang ens3 ay naka-static sa 172.16.16.20/24 na may routes papuntang 10.0.0.0/8 at 192.168.21.0/24 via 172.16.16.16)

* OPENSEARCH TELEMETRY SCRIPT:
  - I-run ang custom Gemini AI script para humugot ng CPU/RAM logs:
    python3 get_syscollector_logs.py
