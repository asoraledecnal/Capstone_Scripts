------------------------------------------------------------------------
Ang Wazuh Manager ang nagsisilbing SIEM at HIDS(Host-Based Intrusion Detection System) na sumasalo ng mga logs mula sa endpoints at firewalls[cite: 16].

[Automated Mitigation (wazuh_orchestrator.py)][cite: 16]

2. Ipapa-ignore ang alert kung ang process ay lehitimo (e.g., TiWorker.exe, chrome.exe)[cite: 16].
3. Kung kumpirmadong malicious, magpapadala ang script ng XML payload sa REST API ng Sophos XG gamit ang wazuh_api_user credentials[cite: 16].
4. I-a-add ng Sophos ang target IP sa Wazuh_Blacklist_Group, at agad mapuputol ang koneksyon dahil sa Rule #9 (SOAR_Auto_Block)[cite: 16].

7. ADVANCED ROUTING CONFIGURATIONS (SIMULATION BYPASS)
------------------------------------------------------------------------
Upang maging matagumpay ang external attack simulation (mula Kali Linux papunta sa Remote Worker), kinakailangang i-bypass pansamantala ang default routing behavior ng mga nodes. Dahil naka-Full Tunnel ang SSL VPN ng remote worker (tun0), lahat ng return traffic ay pilit na ipinapadala sa Sophos XG Hub, kaya nagkakaroon ng 100% packet loss kapag sinusubukan itong i-ping ng external attacker.

Narito ang mga ipinatupad na Static Routes para maayos ang asymmetric routing problem sa simulation environment:

1. KALI LINUX (ATTACKER NODE) ROUTING:
   - Problem: Ang default gateway ng VMware (192.168.202.2) ay hindi alam ang daan papunta sa 10.10.10.0/24 subnet.
   - Solution: Nagdagdag ng explicit route papunta sa VyOS ISP Core.
   - Command Applied: 
     sudo ip route add 10.10.10.0/24 via 192.168.202.135

2. REMOTE WORKER (TARGET NODE) RETURN PATH:
   - Problem: Ang default gateway ay na-override ng tun0 (VPN), kaya ang reply packets papunta kay Kali (192.168.202.144) ay naliligaw papasok sa Batangas Hub.
   - Solution: Nagdagdag ng static route para i-force ang traffic na dumaan sa physical interface (ens3) papunta sa VyOS gateway (10.10.10.1).
   - Command Applied:
     sudo ip route add 192.168.202.0/24 via 10.10.10.1

RESULT:
Pagkatapos mai-apply ang mga routing configurations, naging successful ang end-to-end communication. Nang i-execute ang `./ssh_bruteforce.sh` laban sa 10.10.10.11, matagumpay itong na-detect ng Wazuh Agent at nag-trigger ang SOAR Orchestrator para i-block ang attacker IP sa Sophos XG.
